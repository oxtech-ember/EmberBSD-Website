01 / THE SYSTEM

An OS an agent
can read end to end.

EmberBSD keeps the kernel, C library, utilities and ports in one open project. An agent studies that system and can adapt it for one user. Companion projects stay optional.

02 / CREATURES

One family, from a
microcontroller to the home.

Creators bring creatures to life on one OS family: microcontrollers, single-board computers, and — as the work lands — phones, tablets and TVs. A shared name is not shared support.

Microcontrollers

ESP32-S31 now. STM32H7 next.

The ESP32-S31 port boots from flash: 16 MB PSRAM, a read-only root, partial WPA2 through closed vendor libraries, and one of two cores. Spark is the agent meant to bring this class of device to life. A recorded Spark launch is the GCC16 AArch64 board build; this profile does not yet record that agent run. STM32H7 is the next microcontroller target and is not supported.

ESP32-S31 profile ↗ Spark agent ↗

Single-board computers

Pi 5, CM5 and A733.

Raspberry Pi 5, Compute Module 5 and Allwinner A733 boards (Orange Pi Zero 3W and Zero 4) have public profiles with scoped checks. Cross-compilation uses the SDK workspace and GCC16. Agent skills cover bring-up, ports and day-to-day use. Read the profile before treating a function as available.

Board catalog ↗ SDK workspace ↗ Agent skills ↗

IN PROGRESS

Phones, tablets and TVs.

Second life for devices vendors no longer support: EmberBSD with Plasma Mobile, installed over a USB cable, and Plasma Bigscreen so a TV can become a smart screen. This is a direction, not a release, and not a promise for every phone. One YS-M33 wall tablet (Allwinner A133) has a USB-C installation recorded on a single factory sample. Plasma Mobile and Plasma Bigscreen are source ports without an accepted session. No phone model is supported yet.

YS-M33 profile ↗ Plasma Mobile probe ↗ Plasma Bigscreen probe ↗

The aim is one ecosystem across your devices, up to the smart home. Smart-home software in Ports — MQTT, Zigbee, Thread and controllers — is a set of source probes, not a finished home image. Read the smart-home probes ↗

SCOPED PROFILE

Orange Pi 6 Plus / CIX P1. A profile is published. Scoped checks include a debug console, a reduced persistent root, bounded Ethernet and Wi-Fi, button shutdown and a VPU bootstrap. GPU and NPU operation are not accepted. Read the profile. Sharing a SoC with another board does not establish support.
