WHY THIS FOUNDATION

Built the Unix way.

Understand the parts. Connect them through clear interfaces. Change the layer that needs to change.

A coherent system.

EmberBSD is an independent NetBSD fork. Its kernel, libraries and base tools form one system, with portability at its roots.

Explore the foundation ↗

Shared fixes. Shared progress.

One current Ports recipe owns a dependency and its patches. Fix it there, then rebuild the affected consumers.

A fix should reach the next person who builds, too.

How Ports shares the work ↗

Permissive foundations.

EmberBSD’s own additions use BSD-2-Clause. Spark’s new code does too. Imported components keep their own licenses and notices.

BSD ROOTS

A long history.
A new chapter.

NetBSD gives us a portable foundation. The wider BSD family has built tools for very different worlds.

That history inspires EmberBSD. Our devices still need their own evidence.

04 / FIND YOUR FOUNDATION

Small board.
Big possibilities.

One OS family, different device profiles. Choose your board by the functions your project needs. Each profile records what works and what remains.

BCM2712 / ARM64Raspberry Pi 5Boot, connectivity and peripheral checks↗ BCM2712 / ARM64Compute Module 5A module for your own carrier and enclosure↗ ALLWINNER / ARM64A733 · Zero 3WBoard-specific graphics and NPU work↗ ESPRESSIF / RISC-VESP32-S31A small microcontroller profile with MMU↗

These are documented profiles, not complete support for every peripheral. Check the board revision, tested scenario and recovery path before you build.

All device profiles ↗
What is still in development?

Phone, tablet, TV and smart-home profiles need further integration and hardware checks. No phone model has complete support. FreeCAD and KiCad acceptance, full mobile sessions and general NPU model execution remain open.

The SDK has host build tools. Stable application contracts for Runtime are still being designed. Spark's permanent installation and complete device workflows need further acceptance. A VM result does not establish physical-board support.
