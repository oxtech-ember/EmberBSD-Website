03 / GET STARTED

From source
to your next device.

Start with the public instructions for your target. Pin the source revision and keep the kernel, modules, firmware and userland compatible.

  1. 01

    Choose your target

    Start with device selection, image availability and verification. Read your board's boot path, tested functions and recovery requirements.

    Quick Start ↗
  2. 02

    Install and check first boot

    Use a full image with compatible local sets. The amd64 VM walkthrough starts with a new virtual disk and checks boot without installation media.

    VM installation guide ↗
  3. 03

    Configure and keep it working

    Set up accounts, networking and SSH. Add applications from Ports and Examples, then prepare updates with backups and a recovery path.

    User Guide ↗
